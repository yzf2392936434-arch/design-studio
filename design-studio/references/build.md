# 制作网页、原型和 PPT

## 网页与交互原型

1. 按任务分配首屏。产品页写清产品与主动作，作品集把代表作放在前面，后台明确当前状态和频繁操作。做活动页面时核对档期、价格、联系方式与用户提供的渠道。将必要证据放到决策点附近。
2. 建立一个稳定的版心、阅读顺序和栅格。根据内容决定每个模块的分量。桌面多栏在移动端按任务顺序重排。先定字级、断行、间距与图片比例，再增加装饰或微动效。
3. 用现有品牌资产、真实产品图或具有许可的素材。素材不足时使用明确标注的占位，或者让版式在无图情况下成立。添加摄影时让光线、色调和裁切与周围内容一致。中文字体设常见字形回退，并复查标点、数字、长标题和中英混排。
4. 实际实现表单、菜单、弹窗、标签页或原型路径。把加载、空状态、成功、失败、禁用和键盘焦点做在能出现的位置。动画使用可减少的模式。复用项目现有路由、组件、变量和依赖。用户交付成品网页时按当前环境和需求提供可打开的预览或可维护的源文件。
5. 用浏览器检查窄屏、宽屏和需要的中间断点。试一次核心交互和至少一个异常状态。检查溢出、图片加载、焦点可见、正文对比和控制台错误。截图范围和结果以实际执行为准。

## 演示文稿

1. 把每页的主要信息写成一句结论。用产品照片、数据对比、步骤或案例支持结论。按受众选择讲述顺序，并保留标注来源与必要限定。用户给模板时用实际版式、页幅和字级。
2. 可编辑 PowerPoint 使用当前可用的 PPTX 生成能力。标题、正文和关键图形优先保留为 PowerPoint 对象，照片作为独立图层。涉及精确数据时保留数据源及单位，适用时采用可编辑图表。复杂视觉按可编辑性调整，同时保持用户要求的版式。
3. 生成后渲染每页，检查文字是否溢出、字形是否缺失、图表有没有遮挡或截断。可编辑性的判断来自文件对象或在软件里的实际验证。若当前环境只支持 HTML 或提纲，按可提供的具体格式交付并说明限制。

## 电商图文与小红书

输入优先用商品图、产品标题、明确卖点、版面尺寸和投放场景。设计先定主体和阅读路径，再处理光影、道具、纹理与商品文字。小屏封面留出裁切区。产品规格、价格、活动条款和功效文案与原始资料核对。设计稿、图片或可编辑源文件根据当前环境与用户要求交付。
